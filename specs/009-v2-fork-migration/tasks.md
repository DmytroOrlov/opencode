# Tasks: OpenCode Fork Migration to V2

**Input**: Design documents from `specs/009-v2-fork-migration/`

**Prerequisites**: [spec.md](spec.md), [plan.md](plan.md), [research.md](research.md), [data-model.md](data-model.md), [quickstart.md](quickstart.md), and [contracts/](contracts/).

**Tests**: Deterministic focused tests are required by the accepted specification. No live GPU inference is required.

**Organization**: The four stages follow the paused rebase commit order. Story labels retain specification traceability: Stage 0 is US1, Stage 1 is US5, Stage 2 applies the compact-control slice of US6, and Stage 3 contains US2, US4, US3, and the deferred fallback/pair-selection slice of US6. There are no generic setup or foundational code tasks: the V2 monorepo and shared infrastructure already exist, and the rebase stages define the actual dependencies.

**Checklist format**: `- [ ] Txxx [P?] [USn] Description`. `[P]` appears only for the separate AI provider adapter tasks and locale catalog task, after their shared contracts are established.
