# State and transitions

- **Committed document:** JSONC bytes, mode and decoded complete configuration. Sparse patch applies to the latest serialized commit; omission is unchanged, null explicitly clears, absence retains legacy default `mlx/qwen3.8-27b`/`xhigh`. Candidate validates as a complete document. Equal candidate is a no-op.
- **Update reservation:** monotonic update-owner entry position, independent of validation completion. Invalid/cancelled positions retire; valid positions commit in order. A revision is eligible for staging only after validation, and an older position cannot supersede a later accepted one.
- **Runtime intent:** process-local `(revision, selection | null)` with ownership-safe cleanup. Effective value is latest active eligible intent, else latest published committed value, else legacy resolution. Cleanup of C exposes committed B only if C is still current; it never deletes D. Restart reconstructs only from disk.
- **Commit/publication:** Before rename, the old document and readers remain authoritative; rename commits new bytes. Before coherent publication, block or explicitly degrade protected readers until reconciliation and report committed-but-unpublished failure. Coherent publication makes the new state visible to relevant protected readers. Thereafter a real mandatory completion failure preventing success is committed-and-published failure; optional housekeeping failure is diagnostic and success remains possible. Mandatory resource and lease release cannot be abandoned. No-op clears only its own current intent. Operation roles require the narrow verification in research.md.
- **Admission lease:** process-wide shared generation or exclusive writer ownership, interruptible while queued, released exactly once. Cancellation across rename completes/cleans forward.
- **Attempt snapshot:** immutable dispatched `(model, variant)` and attempt attribution; a pending decision resolves current eligible fallback after backoff at dispatch. Retry caps, already-attempted guards, compaction and uncertain external tool effects remain authoritative.
