# Embedded configuration and admission contract

**Coverage** FR-001–003, SC-001 and 011 FR-010.

The public `OpenCode.create` scope owns one embedded host. Session generation uses the existing session request and run coordinator. `experimental.config.update` uses `PATCH /api/experimental/config`, and the protected read uses `GET /api/config`. Existing payloads, response and typed failure identities remain the contract. See `packages/protocol/src/groups/config.ts` and `packages/server/src/handlers/config.ts`.

1. Resolve the effective writable global config resource at host acquisition. The effective Config FSUtil value supplies namespace and directory evidence and remains the filesystem used for writes in every host graph. The platform filesystem owner supplies an opaque local token, transparent wrappers forward it and each separate virtual store supplies its own token. Equivalent references within one namespace share a coordination pair. Distinct directories or backing stores can progress independently even when their paths and inode data match. An unverified namespace or directory identity fails startup with scoped cleanup. Host-local events, database, user state, plugins and location scopes remain separate in both cases.
2. A generation holding shared admission bars replacement in that resource. A valid fallback mutation can stage before entering the exclusive commit window. Generation recovery sees current accepted intent while the protected reader still sees committed bytes. A durable update still uses candidate validation, sparse reapplication, atomic rename, refresh and required notification in the Config owner.
3. Reservations linearize commits by entry. Staged intent uses latest accepted revision. Rejected candidates stage nothing. Omission preserves intent and explicit null disables fallback. Cancelled writers retire their own reservation and override. No already dispatched model is retargeted.
4. Queued cancellation removes the waiter and causes zero renames. Before the existing masked commit window, interruption unwinds the reservation and acquired lease. Once the transaction enters that window it finishes or cleans up forward. Successful rename immediately advances resource commit revision. Even on a publication error, later protected reads reconcile against the committed document or surface failure.
5. Disposing a host releases its participation. Closing A during generation lets surviving B progress. Closing B with a queued writer retires B's work without releasing A's admission. Host graph teardown and consumer callbacks never evict a pair still referenced by a sibling. These behaviors apply to both standard Location graphs and the SDK private instance selector.

File entry names and overlay precedence stay governed by Config. The coordination key covers the containing writable directory, including before either config file exists. A leaf symlink or hard link in an otherwise distinct directory does not turn two replacement slots into one. Directory aliases are resolved at startup. Concurrent external directory replacement or retargeting and coordination across OS processes are outside the lifetime contract.
